# 🕌 Adhan – Horaires de prière

**Adhan** est une application iPhone élégante et précise qui vous permet de consulter les horaires de prière où que vous soyez dans le monde. Simple, fiable et respectueuse de votre vie privée.

---

## 📱 Description

Adhan transforme votre iPhone en un compagnon spirituel quotidien. Restez connecté à votre foi avec des horaires de prière exacts, des rappels personnalisés, une boussole Qibla intégrée et bien plus encore. L'application est conçue avec une interface épurée dans le plus pur style Apple, offrant une expérience utilisateur intuitive et agréable.

---

## ✨ Fonctionnalités principales

### 🕌 Horaires de prière précis
- Calcul automatique basé sur votre position géographique
- Plusieurs méthodes de calcul disponibles (Ligue islamique mondiale, Autorité générale égyptienne, Université des sciences islamiques de Karachi, etc.)
- Mise à jour automatique selon votre localisation

### 🔔 Rappels personnalisés
- Notifications pour chaque prière
- Choix de différents sons d'adhan
- Possibilité d'activer/désactiver les rappels pour chaque prière

### 🧭 Boussole Qibla
- Direction précise vers La Mecque
- Interface intuitive et facile à utiliser
- Calibration automatique

### 📅 Calendrier islamique
- Dates importantes du calendrier hégirien
- Événements religieux à venir
- Conversion entre calendriers grégorien et hégirien

### 🌍 Localisation automatique
- Détection automatique de votre ville
- Recherche manuelle parmi des milliers de localisations
- Mode hors ligne disponible

### 🔒 Confidentialité totale
- Aucune collecte de données personnelles
- Toutes les informations restent sur votre appareil
- Protection par Face ID / Touch ID disponible

## 🚀 Utilisation

1. **Téléchargez** l'application depuis l'App Store
2. **Autorisez** la localisation pour des horaires précis
3. **Choisissez** votre méthode de calcul préférée dans les paramètres
4. **Activez** les rappels pour ne jamais manquer une prière
5. **Utilisez** la boussole Qibla pour vous orienter correctement

---

## ❓ Questions fréquentes (FAQ)

### Comment sont calculés les horaires de prière ?
Les horaires sont calculés selon votre position géographique et la méthode de calcul choisie (musulmans du monde, Ligue islamique mondiale, etc.).

### Puis-je utiliser l'application hors ligne ?
Oui, une fois les horaires téléchargés, vous pouvez les consulter sans connexion internet.

### L'application collecte-t-elle mes données ?
Non, Adhan ne collecte aucune donnée personnelle. Toutes les informations restent sur votre appareil conformément à notre politique de confidentialité.

### Quelles méthodes de calcul sont disponibles ?
Nous proposons plusieurs méthodes : Ligue islamique mondiale, Autorité générale égyptienne, Université des sciences islamiques de Karachi, et plus encore.
